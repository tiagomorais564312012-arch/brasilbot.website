O que queremos oferecer

Feito para ser útil.

O objetivo é reunir ferramentas práticas sem complicar a gestão da comunidade.

01 / SEGURANÇA

Moderação

Recursos para apoiar a gestão da comunidade e ajudar a manter as conversas organizadas.

02 / COMUNIDADE

Boas-vindas

Uma forma mais clara e acolhedora de receber novos membros.

03 / ATIVIDADE

Participação

Possíveis ferramentas para incentivar a atividade e a interação entre membros.

04 / UTILITÁRIOS

Comandos úteis

Acesso simples a tarefas comuns, de acordo com as possibilidades da plataforma.

05 / PERSONALIZAÇÃO

Configurações

O objetivo é permitir que cada comunidade adapte o bot às suas necessidades.

06 / CONTROLO

Painel web

Uma interface própria para gerir as opções que forem suportadas pela integração.
