FAQ

Alguma dúvida?

Algumas respostas sobre o BrasilBot.

O que é o BrasilBot?

É um projeto de bot para o Yapper, pensado para a comunidade brasileira, com foco em ferramentas de comunidade, moderação e diversão.

Já está tudo funcional?

Não. Esta página apresenta o projeto e as funcionalidades planeadas. Cada função precisa de ser implementada e testada com a API do Yapper.

O dashboard já funciona?

A secção do dashboard é, por enquanto, uma prévia visual. Um painel funcional precisa de backend e de uma integração de autenticação segura.

Como posso acompanhar o projeto?

Adiciona aqui o link oficial do BrasilBot no Yapper ou o teu link de suporte quando estiverem disponíveis.
