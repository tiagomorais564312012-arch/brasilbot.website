Questions

Good to know.

Some answers about the current state of the project.

The public submission is currently under review. The Add to Server button will need an official installation link before it can install the bot.
The website does not have live authentication yet. We need to confirm an official Yapper sign-in method before implementing a secure login.
Not yet. The dashboard is currently an interactive visual preview. Real server management requires a backend, authenticated users, verified permissions and working API integration.
The project is being planned around free tools and hosting tiers where possible. Third-party services can have limits or change their free plans, so completely unlimited free operation cannot be guaranteed.
Visit the Yapper Developers documentation for official API and bot development information.
